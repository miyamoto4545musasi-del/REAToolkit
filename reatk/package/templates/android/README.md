## What you have to add

1. **`libretro.h`** into `app/src/main/cpp/` (from libretro-common).
2. **A core** built for Android into `app/src/main/jniLibs/<abi>/`, named
   `lib@@CORE@@_libretro_android.so`. The app finds it by that name. No core
   binary is generated or shipped by this toolkit.
3. **BIOS/firmware**, if your core needs them, into the app's files directory
   (`/data/data/@@BUNDLE_ID@@/files`, or push them with `adb`). The host hands
   that path to the core as its system directory.
4. **A signing key.** The project is unsigned; build it with your own.

## Known limits

* Audio is written to AAudio without a resampler; a core whose sample rate the
  device will not accept runs silent rather than wrong.
* Save states and rewind are not wired up - `retro_serialize` is not bound.
* The control layout comes from the manifest, so edit
  `assets/reatk/manifest.json` (or re-run the toolkit's `touch-controls`
  plugin with `--set layout=...`) rather than the Kotlin.
