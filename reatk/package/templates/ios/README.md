## What you have to add

1. **A core.** iOS will not `dlopen` one in a sideloaded app, so link a
   libretro core as a static library or embedded framework, implement
   `EmulatorCore` over its `retro_*` functions, and set `EmuCore.shared` to
   your implementation in `AppDelegate`. Nothing is bundled here.
2. **A ROM and any BIOS files.** Copy them into the app's Documents folder
   through Files; the app picks up the first `.nds`/`.gba` it finds there and
   hands that folder to the core as its system directory.
3. **A signing identity.** `scripts/build_ipa.sh` produces an *unsigned* IPA;
   sign it yourself for your own device.

## Known limits

* Frames are presented through `CALayer.contents`, which is fine for a scaled
  256x384 image. For shaders or high internal resolution, swap in `MTKView`.
* No save states: the protocol has no serialise call yet.
* A JIT-capable core needs entitlements this project does not request.
